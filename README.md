## Sobre mim

Sou Gabriel Camarate, desenvolvedor full stack no Rio de Janeiro e estudante de Análise e Desenvolvimento de Sistemas na Universidade Veiga de Almeida, com conclusão prevista para outubro de 2026. Construo aplicações web e automações com React, TypeScript, Next.js, Python e PostgreSQL.

Tenho trabalhado com **Cloudflare Workers, D1 e R2** em aplicações e integrações. Na Rakmma, desenvolvo uma plataforma web de oportunidades geográficas, com componentes em Workers e R2. Também desenvolvo produtos próprios e soluções para clientes, unindo interface, regras de negócio e operação.
